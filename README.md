## About

PRIMUS Olympiad is a learning platform built to help young students (Classes 3–8) prepare for Olympiad exams through:

- **Live discussions** — interactive sessions with mentors and peers
- **AI-powered practice tests** — adaptive tests that target each student's weak areas
- **Expert guidance** — structured support from experienced educators

## Features

- 📘 **Course Management** — organize and manage courses with ease
- 👥 **Student Tracking** — monitor student progress and attendance
- 🏅 **Grading System** — efficient grading and report generation
- 📊 **Analytics** — gain insights with powerful, data-driven analytics

## Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/your-org/primus-olympiad.git
cd primus-olympiad
npm install
```

### Running locally

```bash
npm run dev
```

The app will be available at `http://localhost:3000` (or your configured port).

### Environment variables

Create a `.env` file in the project root:

```env
VITE_API_URL=your_api_url_here
VITE_AUTH_SECRET=your_auth_secret_here
```
